# Curriculum

Ten units take the learner from greetings to holding a simple conversation. Each unit has a communicative goal (`canDo` in `src/content/data/units.json`) and teaches the words, sentences, questions and grammar needed to reach it.

## Concept registry

These ids are reserved. A unit's lexicon file must define all of its ids (it may add more, which must then be added here). Sentence and Q&A tokens may link to any id from the same or an earlier unit. If a planned id turns out to be wrong for a language (no good equivalent), still define the concept and leave that language out.
