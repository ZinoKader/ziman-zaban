# Curriculum

Twenty units take the learner from greetings to holding a simple conversation (units 1 to 10, level A1) and then to everyday topics like health, shopping, travel and work (units 11 to 20, level A2). Each unit has a communicative goal (`canDo` in `src/content/data/units.json`) and teaches the words, sentences, questions and grammar needed to reach it.

## Concept registry

These ids are reserved. A unit's lexicon file must define all of its ids (it may add more, which must then be added here). Sentence and Q&A tokens may link to any id from the same or an earlier unit. If a planned id turns out to be wrong for a language (no good equivalent), still define the concept and leave that language out.
